# AZMARA original town terrain progression — asset brief

## DEC-057 — Desert Town and continental Region

Date: 10 October 2026. This new first draft supersedes the coastal runtime appearance recorded below; every prior original remains preserved. Built-in ImageGen produced five original opaque PNGs, copied byte-for-byte into the project. No CLI, API key, download, cropping, resampling, colour processing or alpha cleanup was used on these terrain assets. The separate Founder-authorized alpha-only building-atlas cleanup does not apply to them.

The shared area is now a Region: geographic space for future independent towns, not a single city, country or island. Town → Region → World uses fictional desert basins, river corridors, dunes and oases. The existing 23 town roles and stable save identities remain; river access preserves the current port roles without implementing new transport rules. Sixteen ordinary regional locations plus one locked premium preview remain, with new land-based anchors chosen to avoid ridges/water. No actual other players, ownership, purchases, routes or production are simulated.

Town terrain uses a generated bare level1 base and generated developed level20 base per profile. Levels5/10/15 add original code-native rough routes, refined earth routes and restrained stone/path-edge details over the bare base. Levels25–50 add distinct cosmetic overlay stages over developed ground. Buildings have all eleven raster milestones independently. These cosmetic paths/gardens are not functioning infrastructure. Native remains paused.

All five sources were viewed before copying, inspected again where used as edit targets, and accepted by root and a second visual reviewer. Native dimensions/opacity checked with sips: desktop1672×941, compact1254×1254, Region1536×1024, all opaque. cmp verifies every copy against the selected generated original. Visual review finds arid continental identity, broad usable clearings, registered riverbank silhouettes and no buildings/UI/sacred content; numerical marker registration and rendered-stage proof belong to the separate browser checks.

## Intended progression

- Level 1: broad primitive bare ochre earth with sparse coarse grass. The original natural perimeter and water remain lush; no new paths or civic landscaping are introduced.
- Level 5: modest grass and rough, well-trodden earth routes. This is deliberately a subtle step below the existing warmer level-10 clearing.
- Level 10: original artwork unchanged.
- Level 15: restrained pale stone footpaths, occasional low edge planting, broad free land between paths.
- Level 20: coherent maintained paving, small landscaped edges and flush irrigation-edge detailing; still broad usable land, with no background buildings.
